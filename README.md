# Arduino LED Blink QA System

LED blinking using Arduino Uno with QA issue tracking and documentation.

## Overview

This project demonstrates a basic LED blinking circuit using an Arduino Uno.

The project also uses GitHub Issues, branches, commits, and pull requests to track and fix QA issues.

## Components

- Arduino Uno
- LED
- 220 Ω resistor
- Jumper wires

## Wiring

Connect the components as follows:

```text
Arduino D13 → 220 Ω resistor → LED anode (+)
LED cathode (-) → GND
